# Data Dictionary & Leakage Audit (v1)

## Target
`late_delivery_risk` (DataCo `Late_delivery_risk`): 1 if the delivery was late.

## Leakage audit - why these columns are banned from features
DataCo's label is derived from scheduled vs. actual shipping dates. Any column
computed from the actual shipment outcome leaks the label and produces the
~99% accuracies seen in parts of the published literature. Banned
(`pisdr.data.LEAKAGE_COLUMNS`): `Days for shipping (real)`, `Delivery Status`,
`Late_delivery_risk` (the raw label column itself), `shipping date (DateOrders)`.
Rule: a feature is admissible only if it is knowable before the outcome.

## Synthetic schema (development/tests only)
order_date, scheduled_days, port_congestion (0-1), disruption_window (0/1,
marks an injected shift period), order_value, units, late_delivery_risk.
Generated by `pisdr.data.make_synthetic_shipments` with a documented
data-generating process. Synthetic results are never reported as real.

## External indicators (planned joins)
NY Fed GSCPI (monthly pressure index), GDELT events, NOAA Storm Events -
joined on date/region only with values published before the prediction date.
